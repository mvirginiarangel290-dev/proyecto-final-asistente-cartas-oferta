# Proyecto Final - Asistente de Cartas Oferta

Automatización de la generación de cartas oferta para proveedores MRO en Saint-Gobain, usando n8n, Airtable e IA (OpenAI). El sistema lee el email del proveedor, extrae los datos con IA, espera aprobación humana (HITL), genera la carta oferta (Word y PDF) y avisa al pasante para su carga en Procontract.

## Documentos de entrega (5)
1. Diagrama de arquitectura 
2. Estructuras de datos 
3. Matriz de optimización de costos 
4. Seguridad y resiliencia 
5. Dashboard de control
